SEGURIDAD INTELIGENTE

¿Qué es CENTINELA-X?

CENTINELA-X es una plataforma de videovigilancia apoyada por Inteligencia Artificial que analiza imágenes de video para identificar eventos de interés, generar alertas y conservar evidencia.

01

Video

Utiliza una fuente de video para realizar el monitoreo del espacio.

02

Inteligencia Artificial

El sistema analiza los frames del video mediante modelos de detección basados en IA.

03

Detección

Identifica objetos configurados para su detección y evalúa el nivel de confianza.

04

Alertas y evidencia

Cuando se detecta un evento, se registra, se conserva evidencia y puede generarse una alerta.

TECNOLOGÍA CENTINELA-X

¿Cómo funciona CENTINELA-X?

El sistema procesa una fuente de video y utiliza modelos de Inteligencia Artificial para analizar las imágenes, identificar objetos y registrar eventos de interés.

01

Fuente de video

El sistema recibe una fuente de video para iniciar el proceso de análisis.

02

Procesamiento

Los frames del video son procesados para que puedan ser analizados por los modelos de IA.

03

Inteligencia Artificial

Los modelos de detección analizan las imágenes para identificar los elementos configurados.

04

Detección

El sistema identifica las detecciones y considera el nivel de confianza obtenido por el modelo.

RESULTADO

Registro de eventos y evidencia

Las detecciones relevantes pueden asociarse con un evento para conservar evidencia y generar una alerta dentro del flujo definido por el sistema.

TECNOLOGÍA

Inteligencia detrás de CENTINELA-X

CENTINELA-X integra diferentes tecnologías para procesar video, analizar imágenes y realizar detecciones mediante Inteligencia Artificial.

01

YOLO

DETECCIÓN DE OBJETOS

Modelo de visión computacional utilizado para detectar objetos dentro de los frames del video y obtener información sobre las detecciones realizadas.

02

Python

PROCESAMIENTO

Lenguaje utilizado para integrar el procesamiento de video, los modelos de Inteligencia Artificial y la lógica principal del sistema.

03

OpenCV

VIDEO E IMÁGENES

Biblioteca utilizada para trabajar con fuentes de video, frames e imágenes durante el proceso de análisis.

04

DeepSORT

SEGUIMIENTO

Tecnología utilizada para realizar el seguimiento de objetos detectados a través de diferentes frames del video.

05

Pose Estimation

ANÁLISIS DE MOVIMIENTO

Tecnología orientada al análisis de la posición corporal para complementar la interpretación de movimientos y comportamientos.
